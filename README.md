# Encrypted chat room

DDrace (or other mods that can chat) encrypted chat room

For development information, visit:

- [Official README.md](https://github.com/ddnet/ddnet/blob/master/README.md) _(contains build and other tutorials)_
- [Building Guide](docs/BUILDING.md)

## Usage:

Enter `]<command>` to execute a command

Basic commands:

- `]help` - List command usage
- `]create` - Create a new room
- `]quit|exit` - Exit the current room
- `]m r[message]` - Encrypt a message and send it
- `]rj|jr i[id]` - Send a join request to someone (by client ID)
- `]crj` - Cancel join request
- `]accept i[id]` - Accept someone's join request
- `]decline i[id]` - Decline someone's join request
